Dev notes

Lanes. In Both view the signed-in person is the left lane and the other person the right lane, matched by line: priority number or hour slot. An entry added as Both spans both lanes in purple.

Long text. On desktop, Week and Month, a row grows to the taller lane and both lanes stretch with it, so lines stay matched. On the Day phone view rows never grow: cap each lane at one line and each Both entry at the width of two lanes (examples: 18 and 36 characters; tune on a device).

Add as Both. It writes one linked entry to both lists, so it shows in Alex's view, Sam's view and Both view. Editing or deleting it changes both.

Colors. Defaults: Sam yellow, Alex green, Both purple, using the theme's readable tints. Each list's color is a setting. Names always appear in the lane headers and the For control, so color is never the only cue.

To-do has no line to match, so it stays one list with a colored circle per owner.
