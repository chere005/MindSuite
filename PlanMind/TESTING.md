# Verification

All tests use disposable fixtures: a temporary data directory, a copied auth library with its own test accounts, no production traffic. During development run focused checks; run the full lists below once, at the end. In a worktree set `PLANMIND_TEST_SITE_LIB=<seancheren-site>/lib` and `COREMIND_REPO=<CoreMind>`.

Both-colour state checks cover repeated picks during a save, serialized writes, and rollback to the last confirmed choice. Day-menu checks cover the phone controls, accessible names, and calendar alignment after the layout change, and the desktop timed grid against origin/main's measured boxes. Server checks run simultaneous prefs saves (`theme.php` section 5) against the lock that serializes them.
